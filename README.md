# Learning Full Stack Development 🚀

My journey learning full-stack web development following the [freeCodeCamp x Scrimba Full Stack Developer Course](https://www.youtube.com/watch?v=LzMnsfqjzkA&t=15496s).

## 📚 Course Information

**Course:** Become a Fullstack Developer from Scratch – Full Beginner's Tutorial  
**Platform:** freeCodeCamp.org (by Scrimba)  
**Duration:** ~47 hours  
**Started:** October 16, 2025 (Thursday)

## 🎯 Learning Goals

- Master HTML, CSS, and JavaScript fundamentals
- Build projects with React, Node.js, and Next.js
- Learn TypeScript, databases (SQL), and testing
- Develop full-stack applications
- Build a strong portfolio of projects
